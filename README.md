# MEAN Starter Template (MongoDB • Express • Angular • Node)

A clean, modern, production‑ready MEAN stack starter template with:

- JWT Authentication (Login + Register)
- Angular Auth Module (Lazy Loaded)
- Token Interceptor
- AuthGuard for Protected Routes
- Dashboard Module (Protected)
- Modular Express API
- MongoDB Integration
- Enterprise‑grade folder structure

This template is designed for developers who want a fast, scalable foundation for full‑stack applications.

---

## 🚀 Features

### **Frontend (Angular)**
- Modular feature‑based architecture
- Auth Module (Login, Register)
- Dashboard Module (Protected)
- Token Interceptor for all HTTP requests
- AuthGuard to protect routes
- Clean UI with SCSS styling
- Angular routing with lazy loading

### **Backend (Node + Express)**
- User registration & login
- Password hashing with bcrypt
- JWT authentication
- Protected routes
- MongoDB connection with Mongoose
- Clean controller/service/model structure
